# CRM Admin Dashboard

Full-stack MERN CRM portfolio project (React + Vite + Tailwind, Express, MongoDB). Work in progress — see `TASKS.md` and `docs/`.

```bash
npm run install:all
cp server/.env.example server/.env
npm run dev:server   # http://localhost:5000/api/health
npm run dev:client   # http://localhost:5173
```
